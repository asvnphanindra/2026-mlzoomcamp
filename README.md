# 2026 ML ZoomCamp

Personal coursework for [ML Zoomcamp 2026](https://courses.datatalks.club/ml-zoomcamp-2026/) (DataTalks.Club).

## Repository structure

```
2026_MLZoomCamp/
├── README.md                 # This file — project overview
├── USER_GUIDE.md             # How to run homework and submit answers
└── HW1/                      # Homework 1 — Introduction
    ├── homework.ipynb        # Solutions (Q1–Q7)
    ├── car_fuel_efficiency_2026.csv
    └── requirements.txt
```

Later modules will follow the same pattern (`HW2/`, `HW3/`, …).

## Quick start

```bash
cd HW1
pip install -r requirements.txt
jupyter notebook homework.ipynb
```

Or open `HW1/homework.ipynb` in VS Code / Cursor and run all cells.
